# EineApp

Eine abo-freie Flutter-App als einfache, erweiterbare Alternative zu klassischen Mood-Trackern.

Der Fokus liegt auf Android und iOS. Die App soll die Funktionen abdecken, die man für ein leichtes tägliches Stimmungs-Tracking wirklich braucht, ohne unnötige Komplexität oder ein Abo-Modell.

## Ziel

- Gefühle schnell erfassen
- Stimmung über den Tag oder über längere Zeit nachvollziehen
- einfache, klare Auswertung statt überladener Oberfläche
- auf Android und iOS konsistent nutzbar

## Aktueller Stand

- iOS nutzt Cupertino mit einer gläsernen Oberfläche
- Android nutzt Material Design als Fallback
- unten gibt es drei Tabs: Start, Emoji und Mehr

## Start

```bash
flutter pub get
flutter run
```
